# Скриншоты для README

Сюда кладутся снимки интерфейса, на которые ссылаются `README.md` и `README.ru.md`.
Нужны именно настоящие снимки живой панели — рисованные макеты в README вводят в
заблуждение: читатель считает их фотографией продукта.

Ожидаемые файлы (PNG, окно шириной ~1440, тёмная тема):

| файл              | что снять                                                        |
|-------------------|------------------------------------------------------------------|
| `servers.png`     | раздел «Серверы»: список с группами, бейджами и плитками-фильтрами |
| `access.png`      | раздел «Доступы»: карточки выдач в разрезе «по кому»               |
| `routing.png`     | раздел «Маршрутизация»: конструктор направления и таблица снизу    |
| `node.png`        | карточка ноды: блоки «кто может подключаться» и «куда может ходить»|

Перед съёмкой стоит убедиться, что в кадр не попали чужие домены, реальные
публичные адреса и имена, которые не хочется публиковать: README читают все.
